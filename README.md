# RentalPayment · 收租月表

個人租賃物業的收發款管理網頁。目前為**靜態互動 demo**（內建示範資料、免登入），
長期規劃以 **Web-based SQLite** 作為資料庫，可部署在自己的手機上離線運轉。

👉 線上 demo：<https://gc999999.github.io/rental-cloud/>

---

## 功能總覽

### 1. 月度總覽
- 上一月／下一月切換（歷史月份唯讀，不可更動金額與收繳狀態）。
- 頂部摘要卡：**應收（本期）** 總額、**待收** 金額與戶數。

### 2. 收租警示
每戶一列，以徽章即時標示三種維度的狀態：

| 維度 | 狀態 |
|---|---|
| 合約 | 履約中／快到期／已到期／已終止／無合約 |
| 搬離 | 房客未搬離／房客已搬離 |
| 繳交 | 租金未收／部分收取／已收／**逾期**（系統依到期日自動判定） |

- 部分收取時顯示「已收 $X／應收 $Y」進度。
- 終止合約的結清尾款以「退出應收」標記。

### 3. 篩選
合約狀態、搬離狀態、繳交狀態三組下拉篩選，可任意組合。

### 4. 租金與費用計算（展開輸入）
每戶可展開三個區塊：

**租金與費用計算**
- **房租（固定）**：本月應收租金，唯讀。
- **變動費用（度數）**：輸入水／電表**新讀值**，系統依前期讀值與單位金額自動計算電費水費；點入輸入框即全選舊值，直接打字覆蓋。
- **特殊事項**：可多條，每條含類型（工單分攤／手動＋－）、事由說明（必填）、金額（必填）——用於維修支出分攤、罰款、調整等一次性項目。
- 僅當有改動時才出現「儲存／取消」按鈕對（取消即還原初值）。

**繳款通知**
- 依該戶當期帳單（房租＋度數＋特殊事項）自動生成的通知文字，唯讀展示，一鍵 **Copy** 貼到通訊軟體。

**收繳狀態**
- **登記收款**：入金登記。
- **收據紀錄**：逐筆列出日期、期間、來源（入金／認列補足）、金額；每筆可**作廢**（紅單，原筆標記「已作廢」）。
- 逾期戶顯示「系統判定：逾期」標籤。

### 5. 繳費／催繳通知
- 逾期戶列面直接提供 **Copy 逾期追繳訊息** 按鈕，複製即用的催繳文字。
- 與「繳款通知」同為唯讀生成＋一鍵複製，不需手動撰寫。

### 6. 租戶管理
- **房客回來了**：空置或已終止的戶別重新入住。
- **終止結算**：進入合約終止結算流程（退出應收由此產生）。
- **⋯ 其他**：次要動作收合於彈層，含取消返回。
- 每列同時顯示戶別代號、建物名稱、房客姓名（空置顯示「—（空置）」。

## Demo 說明

- 本 repo 為 `next build`（`output: "export"`）的純靜態產物，資料為內建示範資料（7 戶：逾期、未收、部分收取、已收、空置、已終止等情境）。
- 免登入、不連外部服務；所有「儲存」為前端互動演練，刷新後回復初值。
- 頁面含 `_.txt`（RSC flight payload）與 `__next.*.txt` 等檔案，為 Next.js 16 App Router 靜態導出的標準產物，執行時會取用，勿刪。
- 根目錄 `.nojekyll` 為 GitHub Pages 所需（避免 Jekyll 吞掉 `_next/` 目錄）。

## 技術

- Next.js 16（App Router）＋ React，靜態導出，自架 woff2 字型。
- 深色／淺色雙模式，手機優先的直式介面。

## 長期規劃

- **Web-based SQLite** 內建資料：資料存於瀏覽器端 SQLite，可匯入匯出備份。
- 部署於自己的手機即可離線運轉（PWA 化），不依賴雲端。
